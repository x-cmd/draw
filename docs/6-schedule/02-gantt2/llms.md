# Core Content

core_features:

  - `/draw/gantt2` — same `m=` source as `/draw/gantt`
  - Bars coloured by status: done, active, critical, milestone
  - A badge on every row — `D` `A` `C` `M`
  - The legend counts the statuses
  - The old `/draw/gantt` is untouched
