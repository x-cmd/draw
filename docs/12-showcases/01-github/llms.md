# Core Content

core_features:

  - Stars by language — donut (`t=market-mono`) and horizontal bar from the same numbers
  - Contributor funnel — Sankey with `t=pipeline`
  - Commits by day — grouped bar, two series per weekday
  - Issues by area — two series (open / closed) per area
  - Repo map — mind map, install link — QR code
