**典型用法**：流量从来源 → 中间步骤 → 终点 的转化路径（如：用户从搜索 → 落地 → 注册 → 付费）。

---

## 参数

| 参数 | 含义 | 必填 |
| --- | --- | --- |
| `nodes=` | 节点列表，逗号分隔 | ✓ |
| `links=source,target,value;...` | 连接：源 → 目标 → 值；分号分隔多条 | ✓ |
| `title=` | 标题 | ✗ |

---



---

## 踩坑

- **节点名引用**：links 里的 `source`/`target` 必须**精确匹配** nodes 里的字符串
- **节点数 ≤ 20**：图变密集；超过考虑分组
- **值为 0 的 link 不画**：用于隐藏不需要强调的路径
- **JSON 写法更适合**：节点多、连接复杂时用 `?d=` JSON
