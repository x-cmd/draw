# draw — SVG-діаграми з даними в URL

SVG-діаграми для епохи ШІ: один ендпоінт `/draw?type=...`, дані в URL і машинно-читабельний `<metadata>` у кожному результаті. Система стилів відповідає дизайн-специфікації, з кількома варіантами для кожного типу.

## Ендпоінти

| type | | |
|---|---|---|
| `pie` | Кільце; `donut=0` = суцільний | ≤100 класів (>9 → Other) |
| `bar` | Груповані стовпчики; `stack=1` | ≤30 груп |
| `hbar` | Горизонтальні стовпчики (рейтинги) | ≤30 смуг |
| `line` | Гладка лінія + градієнт / мультилінія | ≤60 точок |
| `area` | Площина / мультиплощина | ≤60 точок |
| `radar` | Радар | 3–12 осей |
| `gauge` | Індикатор (дуга 240°, значення в центрі) | value+max; кілець ≤8 |
| `scatter` | Розсіювання, дві числові осі, відємні ок | x=&y=, ≤200 точок |
| `combo` | Стовпчики (`series=`) + лінія (`line=`); дві осі від 5× різниці | ≤30 груп, ≤6 серій |
| `sankey` | Діаграма потоків з ширинами | labels=+links=A>B:30, ≤24 вузли |
| `qr` | QR-код | d≤1000 символів, fg/bg, title/unit |

## Версіювання

- без `v`: найновіша версія, кеш 300 с
- `v=N`: зафіксована версія, кеш 1 день
- `immutable` лише для `/c/<hash>`

## Дружньо до ШІ

Кожен SVG вбудовує JSON: `{generator, template, version, spec}` — дані й параметри ходять туди-назад напряму; текст — справжній `<text>`.
