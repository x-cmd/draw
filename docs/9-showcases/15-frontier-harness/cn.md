# AI 编程 Agent 怎么选？FrontierHarness 实测告诉你

现在的 AI 编程工具越来越多。Claude Code、Codex CLI、OpenCode、Cline 等产品都在不断更新，而且几乎每隔一段时间就会出现新的 Agent 工具。

**它们之间究竟有多大差距？换一个 Agent，能不能让同一个模型写出更好的代码？付费使用更贵的工具，真的能获得更好的结果吗？**

为了解答这些问题，FrontierHarness 进行了一次大规模评测：22 个 AI Agent 工具（评测中称 Harness）与 5 个大模型两两组合，在统一的 62 道 Terminal-Bench 任务上各跑 4 轮，共完成 27,280 次计分测试，其中 15,733 次通过，整体通过率 57.67%。

模型之间的平均成本相差 6.3 倍（$0.178 对 $1.113），而 22 个 Agent 之间仅相差 1.65 倍。可以说，选择什么模型，基本就决定了整体成本处于什么档位。

不过，这不代表 Agent 不重要。固定同一个模型时，换用不同 Agent，最贵和最便宜的组合之间，单任务成本仍可能相差 1.8～4.6 倍：Kimi-K3 上是 1.84 倍，DeepSeek-V4.1-Flash 上最悬殊，达 4.63 倍。

例如在 DeepSeek-V4.1-Flash 上，Cline CLI 的单任务成本（$0.494）是 OpenCode 1.19.4（$0.107）的 4.6 倍，但通过率只高出约 2 个百分点（63.3% 对 61.3%）。多花的钱，并没有等比例变成成绩。

另外有个容易被忽略的发现：对全部计分试验的费用归集显示，**64.5% 的模型推理费用花在了最终没有通过的任务上**，其中 52.7% 来自失败任务，11.8% 来自超时任务。

## 三、没有"全能选手"

没有一个 Harness 能在所有模型上都保持最好的性价比，同一个工具换个模型，排名可能剧烈漂移。

总榜第 7 的 Claude Code 最典型。它在五个模型上的排名依次是第 11、9、2、17、6 名：在 DeepSeek-V4.1-Flash 上以 68.15% 排第 2，换到 Muse Spark Open 就跌到第 17（52.82%），而这个组合每任务要花 1.997 美元、每通过一次 3.74 美元，是全部 110 个组合里最贵的一格。

平均来看，同一个 Agent 换模型后通过率的最大落差约为 10 个百分点，落差最大的几个工具超过 15 个百分点。反过来，全场最佳单格是 ZCode 搭配 DeepSeek-V4.1-Flash：68.95% 通过率（248 次试验通过 171 次），单任务成本仅 0.150 美元。而在 Kimi-K3 上，第 1 名 mini-SWE-agent（64.92%）和垫底的 Exo（43.55%）之间相差 21.4 个百分点——选工具的重要性会随着模型不同而剧烈变化。

## 四、给团队的选型建议

1. **不要把模型和 Agent 分开选。** 成本敏感的团队从 DeepSeek-V4.1-Flash 起步：它同时是平均通过率最高（62.79%）、每通过成本最低（$0.279）的模型。预算充足且在意响应稳定性，再考虑 Kimi-K3 这类高价模型。
2. **省心的默认项是 Codex CLI。** 排名稳定在 3～4 名、每通过成本全场最低（$0.935）、超时率全场最低，没有明显短板。
3. **用 Claude Code 之前先确认你的模型。** 它配 DeepSeek-V4.1-Flash 能排第 2，配 Muse Spark Open 却跌到第 17 且费用全场最高——它是需要挑模型的特长型选手。
4. **不要只看 Token 单价。** 平均任务成本、任务通过率、每次通过成本要一起看，尤其要把失败和超时的费用算进去。
5. **最后一定要用自己的任务测试。** 从榜单中挑选 2～3 个候选，用真实代码库和日常开发任务重复测试，再决定是否迁移。
