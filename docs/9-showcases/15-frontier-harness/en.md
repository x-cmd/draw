# Which AI coding agent? FrontierHarness measured them all

AI coding tools keep multiplying. Claude Code, Codex CLI, OpenCode, Cline and their peers ship updates constantly, and a new agent seems to appear every few weeks.

**How big are the differences between them? Can switching agents make the same model write better code? Do the more expensive paid tools actually buy better results?**

To answer these questions, FrontierHarness ran a large-scale benchmark: 22 AI agent tools (called harnesses in the study) crossed with 5 large models, each combination run 4 times over the same 62 Terminal-Bench tasks. That produced 27,280 scored runs, of which 15,733 passed — an overall pass rate of 57.67%.

## 2. Models determine most of the cost

The model influences cost far more than the agent does.

A two-factor variance decomposition of per-task cost over the 110 agent-by-model combinations shows that, on a log scale, **the model explains about 93% of the cost variance, the agent only 2%**, with the remaining ~5% coming from interaction effects between the two.

Average cost differs 6.3x between models ($0.178 vs $1.113), but only 1.65x between the 22 agents. Pick a model and you have mostly picked your cost tier.

That does not make the agent irrelevant. Holding the model fixed, the most and least expensive agents can still differ 1.8–4.6x in per-task cost: 1.84x on Kimi-K3, and a widest gap of 4.63x on DeepSeek-V4.1-Flash.

On DeepSeek-V4.1-Flash, for example, Cline CLI costs $0.494 per task — 4.6x the $0.107 of OpenCode 1.19.4 — while passing only about 2 points more often (63.3% vs 61.3%). The extra money does not convert proportionally into results.

An easy-to-miss finding from aggregating fees across all scored runs: **64.5% of model inference spend went to tasks that ultimately did not pass** — 52.7% on failed tasks and 11.8% on timed-out ones.

## 3. There is no all-rounder

No harness keeps the best value for money on every model; the same tool can swing wildly in ranking when the model changes.

Claude Code, 7th overall, is the clearest example. Its ranks across the five models are 11th, 9th, 2nd, 17th and 6th: on DeepSeek-V4.1-Flash it takes 2nd place with 68.15%, but on Muse Spark Open it drops to 17th (52.82%) — and that combination costs $1.997 per task and $3.74 per pass, the single most expensive cell among all 110.

On average, an agent's biggest pass-rate swing when changing models is about 10 percentage points, with the most volatile tools exceeding 15 points. At the other extreme, the best single cell overall is ZCode with DeepSeek-V4.1-Flash: a 68.95% pass rate (171 passes out of 248 runs) at just $0.150 per task. On Kimi-K3, the gap between the leader mini-SWE-agent (64.92%) and last-place Exo (43.55%) is 21.4 points — how much the tool matters changes sharply with the model.

## 4. Selection advice for teams

1. **Do not pick the model and the agent separately.** Cost-sensitive teams should start on DeepSeek-V4.1-Flash: it is simultaneously the model with the highest average pass rate (62.79%) and the lowest cost per pass ($0.279). Move up to a premium model such as Kimi-K3 only when budget allows and response stability matters.
2. **The worry-free default is Codex CLI.** A steady 3rd–4th rank, the lowest cost per pass overall ($0.935), the lowest timeout rate, and no obvious weak spot.
3. **Check your model before adopting Claude Code.** It ranks 2nd with DeepSeek-V4.1-Flash but 17th with Muse Spark Open, at the highest cost of any cell — a specialist that needs the right model.
4. **Do not look at token unit price alone.** Read average task cost, task pass rate and cost per pass together, and count the spend on failures and timeouts.
5. **Always finish with your own tasks.** Shortlist 2–3 candidates from the table and re-test them on your real repositories and daily development work before deciding whether to migrate.
