# Core Content

core_features:

  - A course timetable: the periods are the rows, the weekdays the columns
  - A release schedule and an on-call roster: rows are items with a date range
  - A team month with thirty-seven things in it, and a personal month
  - October 2026 with the National Day holiday and the make-up workday
  - The year 2026 as twelve mini months, two months side by side, three months with notes

# Key Information

highlights:

  - Every case is a URL that can be pasted into an issue or a README
  - Holidays are data, not logic — the link changes when the arrangement does
  - Dense, real-feeling content: the calendar type is meant for packed schedules

# Use Cases

  - A README that needs the release schedule
  - An issue that needs the on-call rota
  - A school project that needs the timetable
