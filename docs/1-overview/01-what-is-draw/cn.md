# draw —— SVG chart endpoint 速查（13 种图表 + 通用参数 + 数据格式）

---

## 一、端点是什么

`x-cmd/draw` 是单端点 SVG 图表服务：

```
GET  /draw?type=<chart-type>&...     # 返 SVG（图片）
POST /draw?type=<chart-type>&...     # 创永久短链
```

返回的 SVG 内嵌 `<metadata>` 节点，**不是二进制图、是纯文本**——可 grep / diff / 版本管理。

支持 13 种图表：

| type | 图表 | 详细 |
| --- | --- | --- |
| `pie` | 饼图 | 见 [pie](../../2-chart-types/01-data-charts/01-pie/cn.md) |
| `bar` | 柱状图 | 见 [bar](../../2-chart-types/01-data-charts/02-bar/cn.md) |
| `hbar` | 水平柱状图 | 见 [hbar](../../2-chart-types/01-data-charts/03-hbar/cn.md) |
| `line` | 折线图 | 见 [line](../../2-chart-types/01-data-charts/04-line/cn.md) |
| `area` | 面积图 | 见 [area](../../2-chart-types/01-data-charts/05-area/cn.md) |
| `radar` | 雷达图 | 见 [radar](../../2-chart-types/01-data-charts/06-radar/cn.md) |
| `gauge` | 仪表盘 | 见 [gauge](../../2-chart-types/01-data-charts/07-gauge/cn.md) |
| `scatter` | 散点图 | 见 [scatter](../../2-chart-types/01-data-charts/08-scatter/cn.md) |
| `combo` | 混合图 | 见 [combo](../../2-chart-types/01-data-charts/09-combo/cn.md) |
| `sankey` | 桑基图 | 见 [sankey](../../2-chart-types/02-relations/01-sankey/cn.md) |
| `qr` | 二维码 | 见 [qr](../../2-chart-types/06-infographics/01-qr/cn.md) |
| `quadrant` | 四象限决策矩阵 | 见 [quadrant](../../2-chart-types/03-strategy/01-quadrant/cn.md) |
| `compass` | 四向箭头 | 见 [compass](../../2-chart-types/03-strategy/02-compass/cn.md) |

`type=` 图表之外,同一个服务还有几个图形入口,各自一个路径:

| 路径 | 图形 | 详细 |
| --- | --- | --- |
| `/draw/archmap` | 架构图 | 见 [archmap](../../2-chart-types/04-architecture/01-archmap/cn.md) |

| `/draw/echarts` | 任意 ECharts option —— 热力图、箱线图、地图 | 见 [maps](../../2-chart-types/07-maps/01-maps/cn.md) |

## 二、通用参数

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `t=` | 风格 / 主题（如 `evil` / `market-mono` / `progress` / `revenue`） | 各图表默认 |
| `scheme=dark\|light` | 配色方案 | 跟随系统 |
| `num=all\|peak\|none` | 数值标签密度（全标 / 只标最大 / 不标） | `all` |
| `v=1` | 冻结响应（调试 / 缓存用） | — |
| `w=` / `h=` | SVG 宽高（像素或 CSS 单位） | 默认尺寸 |
| `title=` | 标题文本 | — |
| `unit=` | 数值单位（如 `B`、`responses`、`%`） | — |
| `labels=` / `values=` / `series=` | 数据（依图表类型而定） | — |

完整风格 / 主题清单见 [3-styles-themes](../../3-styles/01-style-families/cn.md)；两种数据写法对比见 [5-data-formats](../../4-data-and-api/01-data-formats/cn.md)。

## 三、两种数据写法

每个图表都支持两种数据写法——结果完全等价：

### 写法 A：扁平参数（URL 永远可读）

```
/draw?type=pie&title=Chrome%20holds&labels=Chrome,Safari,Firefox&values=65,18,7
```

### 写法 B：`?d=` JSON（数据复杂时更整洁）

```
/draw?type=pie&d={"title":"Chrome holds","data":[{"label":"Chrome","value":65},{"label":"Safari","value":18},{"label":"Firefox","value":7}]}
```

**选哪种**：
- 数据少（≤ 5 项）→ 用 **A**，URL 短、可分享
- 数据多 / 有结构 → 用 **B**，URL 仍可读

详细对比、JSON schema、边界情况见 [5-data-formats](../../4-data-and-api/01-data-formats/cn.md)。

## 四、GET vs POST

| Method | 用途 | 返回 |
| --- | --- | --- |
| `GET /draw?...` | 一次性 SVG | `image/svg+xml`（或 redirect 到 CDN） |
| `POST /draw?...` | 创建永久短链 | `{ "id": "...", "url": "/d/abc123" }` |

POST 短链适合：
- 文档嵌入的图表（URL 稳定）
- README badge / issue comment
- 长期分享

## 五、返回的 SVG 是什么样

每个 SVG 都长这样：

```xml
<svg viewBox="0 0 600 400" xmlns="...">
  <metadata>
    <title>Chrome holds the browser market</title>
    <desc>Generated by x-cmd/draw</desc>
    <source>/draw?type=pie&amp;labels=Chrome,Safari,Firefox</source>
  </metadata>
  <!-- 实际图形元素 -->
</svg>
```

**关键**：SVG 是**纯文本**，不是 PNG/JPEG 二进制。可以：
- `grep "<text>"` 找所有标签
- `git diff` 看图表变化
- 在 issue / Slack 里直接 paste

## 六、最短上手

```sh
# 饼图
curl "https://x-cmd.com/draw?type=pie&labels=A,B,C&values=10,20,30"

# 折线图
curl "https://x-cmd.com/draw?type=line&x=Jan,Feb,Mar&y=10,20,15"

# 二维码
curl "https://x-cmd.com/draw?type=qr&data=https://x-cmd.com"

# 换暗色主题
curl "https://x-cmd.com/draw?type=pie&labels=A,B,C&values=10,20,30&scheme=dark"

# 冻结版本（缓存友好）
curl "https://x-cmd.com/draw?type=pie&labels=A,B,C&values=10,20,30&v=1"
```

各图表的具体用法见各自专门文章。
