# draw — SVG-графики с данными в URL

SVG-графики для эпохи ИИ: один эндпоинт `/draw?type=...`, данные в URL и машиночитаемый `<metadata>` в каждом ответе. Система стилей следует дизайн-спецификации, по несколько вариантов на тип графика.

## Эндпоинты

| type | | |
|---|---|---|
| `pie` | Кольцо; `donut=0` = сплошной круг | ≤100 классов (>9 → Other) |
| `bar` | Групповые столбцы; `stack=1` в стопку | ≤30 групп |
| `hbar` | Горизонтальные полосы (рейтинги) | ≤30 полос |
| `line` | Гладкая линия + градиент / мультилинии | ≤60 точек |
| `area` | Область / мультиобласти | ≤60 точек |
| `radar` | Радар | 3–12 осей |
| `gauge` | Индикатор (дуга 240°, значение в центре) | value+max; колец ≤8 |
| `scatter` | Разброс, две числовые оси, отрицательные ок | x=&y=, ≤200 точек |
| `combo` | Столбцы (`series=`) + линия (`line=`); две оси при разнице 5× | ≤30 групп, ≤6 серий |
| `sankey` | Диаграмма потоков с ширинами | labels=+links=A>B:30, ≤24 узлов |
| `qr` | QR-код | d≤1000 символов, fg/bg, title/unit |

## Версионирование

- без `v`: свежая версия, кеш 300 с
- `v=N`: закреплённая версия, кеш 1 день
- `immutable` только для `/c/<hash>`

## Дружелюбно к ИИ

Каждый SVG встраивает JSON: `{generator, template, version, spec}` — данные и параметры ходят туда-обратно напрямую; текст — настоящий `<text>`.
