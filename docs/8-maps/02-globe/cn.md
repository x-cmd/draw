# 地球仪与球面图 —— 城市落在球面上,关系走大圆弧

两个端点,一张球。`/draw/globe` 是**真地球仪**:大陆轮廓随服务一起分发
(不用地图服务、不要 API key),城市按经纬度落在球面上,节点之间的边画成
**大圆弧** —— 两点间最短的球面路径,弧稍稍挑起,免得贴住球面被挡住一半。

球是半透明的:背面的点和线淡着画出来(X 光的样子),整张图的信息不丢一半。
配深色底,点上带城市名,悬停能看经纬度。

`/draw/sphere` 是**球面上的关系图**:同样一张球,但没有大陆,也不看位置 ——
给它一张关系图,力导向会把它铺到球面上(固定 seed,同样的图每次摆得一模一样)。

## 参数

| 参数 | 意思 |
|---|---|
| `n=` | 节点:`id;type;label[;sub][;p<纬度>,<经度>]`,可重复。`p` 段定位(纬度 ±90、经度 ±180),不写位置的节点参与力导向 |
| `e=` | 边:`from;to[;label]`,可重复。边走大圆弧,稍微挑起来 |
| `hl=` | 点名:`hl=ash,fra` —— 点到的节点画大一点、带一圈圈(只地球仪有意义) |

地球仪上,**写了 `p` 的节点被钉住**,没写的才参与力导向 —— 所以「全球流量」
那张图里城市纹丝不动,而球面图那种关系图整张都在动。

## 限制

- **`p` 的范围是纬度 ±90、经度 ±180**,超出会被忽略(那一点退回力导向摆位)。
- **力导向的甜区是 30–200 个节点。** 少于 30 个,球面显得空;多于 200 个,
  标签开始互相遮盖 —— 那时候该考虑分层或者换平面图。
- **球面图不看位置。** `/draw/sphere` 里 `p` 段写了也不生效
  (位置是摆出来的,固定 seed,同样的图每次一样)—— 想钉城市,用 `/draw/globe`。
- **深色主题是这张图的固定表情。** 半透明蓝球、亮色弧,为深底设计;
  `scheme=light` 不适用这一族。
- **静态 SVG 是固定相机那一眼**(yaw 20°、pitch -18°,大半张世界尽收眼底);
  要转着看,去 explore 页。

## 跟别的图种的区别

- **`/draw/globe` vs `/draw/sphere`**:一个是**地图 + 城市**(大陆、经纬度、
  `hl=` 点名高亮,适合「全球流量」「数据中心分布」);一个是**球面上的关系图**
  (没有大陆,位置全是力导向摆的,适合「这张关系图换个球面摆法什么效果」)。
- **`/draw/echarts` 地图**:那一页讲等值图(choropleth)—— 给区域填数值的颜色。
  地球仪不讲数值,讲**点与点之间的连接**。
- **`/draw/arch3d`**:三维架构图的高度轴讲流向,地球仪的球面讲地理 ——
  数据有经纬度用地球仪,数据只是上下游用架构图。

图库里还有更多:[/draw/demo/map](https://x-cmd.com/draw/demo/map)。
