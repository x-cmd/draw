# Globe and sphere — cities on a ball, relations along great-circle arcs

Two endpoints, one ball. `/draw/globe` is a **real globe**: the continent outlines
ship with the service (no map provider, no API key), cities drop onto the ball at
their coordinates, and the edges between nodes draw as **great-circle arcs** — the
shortest path across the surface, arched slightly upward so it is not half-hidden
by the ball itself.

The sphere is translucent: points and lines on the far side are drawn faint (an
X-ray look), so the picture keeps half of its information. Dark background, city
names on the dots, coordinates on hover.

`/draw/sphere` is a **relation graph on a ball**: same ball, but no continents and
no fixed positions — hand it a graph and a force layout spreads it over the sphere
(fixed seed: the same graph comes out identical every time).

## Parameters

| param | meaning |
|---|---|
| `n=` | node: `id;type;label[;sub][;p<lat>,<lon>]`, repeatable. The `p` field pins the node (lat ±90, lon ±180); nodes without it join the force layout |
| `e=` | edge: `from;to[;label]`, repeatable. Edges draw as great-circle arcs, arched a little |
| `hl=` | name names: `hl=ash,fra` — the named nodes get a bigger dot plus a ring (globe only) |

On the globe, nodes **with a `p` field are pinned**; only the others take part in
the force layout — that is why the cities in the traffic picture below never drift,
while a sphere-kind graph moves as one piece.

The same relation graph, laid on a ball — no continents, no coordinates, positions
all from the force layout (fixed seed, identical every time). Use it when you want
to see what a graph looks like wrapped around a sphere: nodes around the ball,
edges riding the surface.

## Limits

- **`p` ranges: lat ±90, lon ±180.** Out-of-range coordinates are ignored and the
  node falls back to the force layout.
- **The force-layout sweet spot is 30–200 nodes.** Below 30 the ball looks empty;
  above 200 the labels crowd — time to split the picture or use a flat kind.
- **The sphere kind ignores positions.** On `/draw/sphere` a `p` field has no
  effect (positions are laid out, not written) — pin cities with `/draw/globe`.
- **The dark look is fixed for this family.** Translucent blue ball, bright arcs —
  designed for a dark page; `scheme=light` does not apply here.
- **The static SVG is one fixed camera** (yaw 20°, pitch −18°, most of the world
  in view); to spin it, open the explore page.

## How it differs from the other kinds

- **`/draw/globe` vs `/draw/sphere`**: one is **a map plus cities** (continents,
  coordinates, `hl=` highlighting — for "global traffic", "data-center footprint");
  the other is **a graph on a ball** (no continents, all force-laid — for "what
  does this relation graph look like on a sphere").
- **`/draw/echarts` maps**: that page is about choropleths — colouring regions by
  value. The globe carries no values; it carries **connections between points**.
- **`/draw/arch3d`**: the 3D architecture height axis is about flow; the globe is
  about geography — coordinates in the data, globe on the page; only upstream/
  downstream, architecture diagram.
