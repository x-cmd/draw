# 天梯图示例数据(examples/)

这里的 JSON 是 `x-cmd.com/draw` 天梯图种的数据示例,喂给
`/draw?type=butterfly-ladder&d=…` 或 `?src=…` 即可渲染。
**数据本身比图更值得关注**:它代表我们对外承诺的评分口径。

## 文件清单

| 文件 | 图种 | 维度 | 覆盖 | 数据口径 |
|---|---|---|---|---|
| `ladder-gpu.json` | 双翼 | 游戏(DirectX 12) | 各翼前 20 | **x-cmd/hw 规格指数** |
| `ladder-gpu-100.json` | 双翼 | 游戏(DirectX 12) | 全量 71 vs 34 | **x-cmd/hw 规格指数** |
| `ladder-gpu-ai.json` | 双翼 | AI 推理(GPT-J 级小模型) | 全量 71 vs 34 | **x-cmd/hw 规格指数(外推)** |
| `ladder-gpu-market.json` | 单边 | 「全市场」 | 前 200 | ⚠ **遗留**:PassMark 分 × 0.0836 |

口径分两类的缘由(2026-11-23 决定,记录在 x-cmd/hw 的
`memory/hardware-index.md`「接手决定」与同日的 issue #2 评论):

- **hw 指数**:`index(卡) = 1000 × 模型预测(卡) / 模型预测(GTX 1080 Ti)`。
  锚点的 1000 是**归一化构造出来的真值**,每一张卡的分数都是
  「规格 → 实测」模型的输出,带模型的误差带。**不是任何跑分榜的换算**。
- **遗留换算**:旧示例拿 PassMark 原始 G3D 分乘一个常数,声称
  「GTX 1080 Ti = 1000」——实际 1080 Ti 在那份数据里是 1555。
  这是我们不干的「复刻跑分榜」,正在淘汰。`ladder-gpu-market.json`
  暂留是因为它承诺的是「PassMark 全市场前 200」(我们规格库只覆盖
  ~105 张桌面卡,换掉它 = 改掉覆盖定义,属编辑决定)。

## 两个维度,一把锚点尺,但分数不可跨维度比

同一个 GTX 1080 Ti = 1000,但「游戏 2000 分」和「AI 2000 分」是
不同的物理量,只在各自维度内可比:

- **游戏 = DirectX 12 规格指数**(FP32 + 显存带宽 → 光栅实测拟合,
  134 张卡标定,留一误差 ±10%)。当前榜首:RTX 5090 = 2391。
- **AI 推理 = 加速卡模型的 ai-small 目标**(GPT-J-99 场景,只吃显存带宽;
  标定在 MLPerf v5.0 数据中心卡上,R²=0.88,留一 ±18%)。
  当前榜首:RTX 5090 = 2279。

### AI 维度的诚实边界(重要)

加速卡模型标定在 **8 张数据中心卡**上,**消费卡一张实测都没有**。
所以天梯上每一个 AI 分数都是规格外推,不是测量:

- 误差带 ±18% 是标定域内的留一误差,外推只会更差不會更好;
- 带宽低于标定下限(≈864 GB/s)的卡有 37 张,外推风险更大;
- 大模型(ai-large / llama2-70b)维度**不发消费卡**:标定域内
  留一误差都有 ±42%,且 70B 不是消费场景。

把这些分数当「LLM 跑分榜」用会翻车;它们回答的是
「按规格外推,这张卡的小模型推理大约什么量级」。

## 每个文件自带来源链(`_source`)

hw 指数类文件都带 `_source` 块,四件套缺一不可:

1. `index` —— 指数的定义(哪个模型、哪个目标、锚点是什么)
2. `specs` —— 规格库快照(`data/spec/<date>/spec.tsv`,
   逐行出处在该文件的 `source` 列:厂商官网 / gpuspecs.com)
3. `model` —— 模型文件 + hw 仓 commit
4. `generated` —— 生成器(`hw tools/mkladder.py`)+ 日期;
   `calibrated_on` 注明标定语料私有、永不发布

缺 `_source` 的评分文件不允许进这个目录(规矩在 hw 仓 AGENTS.md)。

## 怎么更新(模型每次重标定后)

```sh
# 在 x-cmd/hw 仓:
python3 tools/mkladder.py        # 重新生成三份,自动渲染验证
# 然后回本仓提交 examples/ 的改动
```

生成器与模型同仓同版本,重标定后重跑即可;模型没变时输出字节不变。
本机直连 x-cmd.com 偶发 reset,带上 `HTTPS_PROXY=http://localhost:2026`
再跑。
