# draw — データを URL に載せた SVG グラフ

> [English](../README.md) | **日本語**

[![JSR score](https://img.shields.io/badge/dynamic/json?url=https%3A%2F%2Fapi.jsr.io%2Fscopes%2Fx-cmd%2Fpackages%2Fdraw&query=%24.score&label=JSR%20score&color=yellowgreen)](https://jsr.io/@x-cmd/draw/score)
[![OpenSSF Scorecard](https://api.securityscorecards.dev/projects/github.com/x-cmd/draw/badge)](https://securityscorecards.dev/viewer/?uri=github.com/x-cmd/draw)


X-CMD Draw は、オープンソースの SVG チャート生成ツールです。データとスタイルを URL に記述するだけで、棒グラフ、折れ線グラフ、サンキー図、システムアーキテクチャ図、マインドマップなど、さまざまな図を生成できます。

チャートは README、issue、PR、ブログ記事、Web ページに直接埋め込めます。画像ファイルのエクスポートやアップロードは不要です。リンクと SVG には機械可読なデータとパラメーターが保持されるため、読者には図が表示され、AI Agent は画像を認識し直すことなく、その内容を読み取り、編集し、再生成できます。

## ひと目で見る

パフォーマンス分析からアーキテクチャ設計、地図、スケジュールまで、図の定義はすべてリンクに保存されています。画像をクリックすると、データの確認、スタイルの調整、再生成ができます。[その他のチャート例を見る ↗](https://x-cmd.com/draw)

## クイックスタート

### 1. Agent に draw の使い方を覚えさせる

以下の Prompt を Web ページを読める Agent に送信してください。draw のホステッドサービスは、アカウント登録や API Key の申請なしで利用できます。

```text
Read and follow https://raw.githubusercontent.com/x-cmd/draw/main/SKILL.md. From now on, whenever you write a README, issue, pull request, blog post, or chat message and need a chart, use x-cmd Draw to generate a link and embed it with image syntax instead of attaching image files.
```

### 2. やりたいことを伝える

使用するデータ、表現したい関係、チャートの使用場所を Agent に伝えます。

```text
README にアーキテクチャ図を追加し、CLI から API、データベースへのリクエストの呼び出し経路を描いてください。
```text

頻繁に使う場合は、[`SKILL.md`](../SKILL.md) をローカル skills をサポートする Agent にインストールできます。Claude Code の場合、`~/.claude/skills/draw/SKILL.md` として保存すれば、一度の設定で以後は要件を直接伝えるだけで済みます。

## 機能

- **🔗 URL がそのまま図になる**：データとスタイルは、読みやすく、比較でき、バージョン管理できるテキストです。リンクは Markdown や Web ページに直接埋め込めます。
- **🤖 人にも AI にも読みやすい**：SVG は表示に使われ、機械可読なデータとパラメーターは、その後の編集や再生成に使われます。画像からデータを推測し直す必要はありません。
- **📊 豊富な図表機能**：データチャート、フローチャート、アーキテクチャ図、マインドマップ、地図、スケジュールに対応し、ECharts を使ってより複雑なデータ関係も表現できます。
- **🖱️ ビジュアルな対話編集**：例をクリックして対話ページを開き、データの確認、パラメーターやスタイルの調整、新しいチャートリンクのコピーができます。
- **🚀 オープンでセルフホスト可能**：TypeScript ベースの Apache-2.0 ライセンス。オンラインサービス、CLI、npm / JSR ライブラリ、Cloudflare Workers へのデプロイをサポートします。

## Agent を使わない場合は、目的に合う方法を選択

### すぐに作図：URL を直接使用

ドキュメント作成、共有、手軽な可視化に適しています。[デモ・対話編集ページ](https://x-cmd.com/draw)を開き、データとスタイルを調整してリンクをコピーできます。URL パラメーターを直接編集することも可能です。

```md
![割合の例](https://x-cmd.com/draw?type=pie&labels=A,B&values=3,2)
```

読者には図が表示され、作成者には編集・レビュー可能なテキストが残ります。

### 一括生成やプロジェクトへの組み込み：CLI またはライブラリ

CI でのチャート自動更新、レポートの一括生成、オフライン利用、アプリケーション統合に適しています。CLI とライブラリは、ホステッドサービスと同じパラメーターを使用します。

```sh
npx @x-cmd/draw --type pie --labels A,B --values 3,2 --out pie.svg
```

コード内で SVG を同期的に生成する場合は、ライブラリをインストールして `draw` を呼び出します。

```sh
npm install @x-cmd/draw
```
```ts
import { draw } from '@x-cmd/draw';

const { svg } = draw({ type: 'pie', labels: 'A,B', values: '3,2', t: 'evil', scheme: 'dark' });
```

Deno では `deno add jsr:@x-cmd/draw` を実行し、`jsr:@x-cmd/draw` からインポートできます。レンダリングコアはネットワークやファイルにアクセスしないため、制限された環境でも実行できます。

### アクセス入口とデータ境界を管理：独自サービスを運用

チームで入口を統一する場合、イントラネットで利用する場合、パブリックサービスに依存したくない場合に適しています。

```sh
git clone https://github.com/x-cmd/draw && cd draw && npm install
npm run serve           # ローカルサービス：http://localhost:8787/draw
bash scripts/setup.sh   # 自分の Cloudflare アカウントへワンクリックでデプロイ
```

`DATA_REPO`、`DATA_BRANCH`、`GITHUB_TOKEN` を設定すると、永続的な短縮リンクを有効にできます。未設定でも通常の GET レンダリングには影響しません。詳しくは[セルフホストガイド](../docs/1-overview/05-self-hosting/ja.md)を参照してください。

## 開発

```sh
npm install
npm run dev      # wrangler dev でローカルサーバーを起動
npm test         # vitest
npm run check    # tsc --noEmit × 3（worker / node / build）
npm run build    # dist/ を生成（npm ライブラリ + CLI）
npm run deploy   # wrangler deploy
```
