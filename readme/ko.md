# draw — 데이터가 URL에 담긴 SVG 차트

> [English](../README.md) | **한국어**

[![JSR score](https://img.shields.io/badge/dynamic/json?url=https%3A%2F%2Fapi.jsr.io%2Fscopes%2Fx-cmd%2Fpackages%2Fdraw&query=%24.score&label=JSR%20score&color=yellowgreen)](https://jsr.io/@x-cmd/draw/score)
[![OpenSSF Scorecard](https://api.securityscorecards.dev/projects/github.com/x-cmd/draw/badge)](https://securityscorecards.dev/viewer/?uri=github.com/x-cmd/draw)


X-CMD Draw는 오픈 소스 SVG 차트 생성 도구입니다. 데이터와 스타일을 URL에 작성하면 막대 그래프, 선 그래프, 생키 다이어그램, 시스템 아키텍처 다이어그램, 마인드맵 등 다양한 그림을 만들 수 있습니다.

차트는 이미지 파일을 내보내거나 업로드할 필요 없이 README, issue, PR, 블로그 글, 웹페이지에 바로 삽입할 수 있습니다. 링크와 SVG에는 기계가 읽을 수 있는 데이터와 매개변수가 유지되므로, 독자는 그림을 보고 AI Agent는 이미지를 인식할 필요 없이 내용을 읽고 수정하고 다시 생성할 수 있습니다.

## 미리 보기

성능 분석부터 아키텍처 설계, 지도와 일정까지 모든 그림 정의가 링크에 저장됩니다. 이미지를 클릭하면 데이터를 확인하고 스타일을 조정한 후 다시 생성할 수 있습니다. [더 많은 차트 예시 보기 ↗](https://x-cmd.com/draw)

## 빠른 시작

### 1. Agent가 draw를 사용하도록 설정하기

웹 페이지를 읽을 수 있는 Agent에 아래 Prompt를 보내세요. draw의 호스티드 서비스는 계정 가입이나 API Key 신청 없이 사용할 수 있습니다.

```text
Read and follow https://raw.githubusercontent.com/x-cmd/draw/main/SKILL.md. From now on, whenever you write a README, issue, pull request, blog post, or chat message and need a chart, use x-cmd Draw to generate a link and embed it with image syntax instead of attaching image files.
```

### 2. 원하는 내용 설명하기

사용할 데이터, 표현하려는 관계, 차트를 사용할 위치를 Agent에 알려 주세요.

> 이 PR에 아키텍처 다이어그램을 추가하고 싶습니다. 먼저 이번 변경의 코드와 논의를 읽고, 요청이 CLI에서 API와 데이터베이스로 이어지는 호출 경로를 그려 주세요. 관련 모듈과 이번에 수정한 위치를 명확히 표시하고, 그림을 PR 설명에 직접 삽입해 주세요.

자주 사용한다면 로컬 skills를 지원하는 Agent에 [`SKILL.md`](../SKILL.md)를 설치할 수 있습니다. Claude Code를 예로 들면 `~/.claude/skills/draw/SKILL.md`로 저장해 한 번만 설정하면, 이후에는 요구 사항을 바로 설명하면 됩니다.

## 주요 기능

- **🔗 URL이 곧 차트**: 데이터와 스타일은 읽고 비교할 수 있으며 버전 관리도 가능한 텍스트입니다. 링크를 Markdown과 웹페이지에 바로 삽입할 수 있습니다.
- **🤖 사람과 AI가 모두 읽을 수 있음**: SVG는 표시에 사용되고, 기계가 읽을 수 있는 데이터와 매개변수는 이후 수정과 재생성에 사용됩니다. 이미지에서 데이터를 거꾸로 추론할 필요가 없습니다.
- **📊 풍부한 그림 기능**: 데이터 차트, 순서도, 아키텍처 다이어그램, 마인드맵, 지도, 일정을 지원하며 ECharts로 더 복잡한 데이터 관계도 표현할 수 있습니다.
- **🖱️ 시각적 대화형 편집**: 예시를 클릭해 대화형 페이지에서 데이터를 확인하고 매개변수와 스타일을 조정한 후 새 차트 링크를 복사할 수 있습니다.
- **🚀 개방적이며 셀프 호스팅 가능**: TypeScript 기반이며 Apache-2.0 라이선스를 사용합니다. 온라인 서비스, CLI, npm / JSR 라이브러리, Cloudflare Workers 배포를 지원합니다.

## Agent를 사용하지 않나요? 적합한 연동 방식을 선택하세요

### 빠른 차트 생성: URL 직접 사용

문서 작성, 공유, 간단한 시각화에 적합합니다. [데모 및 대화형 편집 페이지](https://x-cmd.com/draw)에서 데이터와 스타일을 조정한 후 링크를 복사하거나 URL 매개변수를 직접 수정할 수 있습니다.

```md
![비율 예시](https://x-cmd.com/draw?type=pie&labels=A,B&values=3,2)
```

독자는 그림을 보고, 작성자는 수정하고 검토할 수 있는 텍스트를 유지합니다.

### 일괄 생성 또는 프로젝트 연동: CLI 또는 라이브러리 사용

CI에서 차트를 자동으로 업데이트하거나, 보고서를 일괄 생성하거나, 오프라인으로 사용하거나, 애플리케이션에 통합할 때 적합합니다. CLI와 라이브러리는 호스티드 서비스와 동일한 매개변수를 사용합니다.

```sh
npx @x-cmd/draw --type pie --labels A,B --values 3,2 --out pie.svg
```

코드에서 SVG를 동기적으로 생성하려면 라이브러리를 설치하고 `draw`를 호출하세요.

```sh
npm install @x-cmd/draw
```
```ts
import { draw } from '@x-cmd/draw';

const { svg } = draw({ type: 'pie', labels: 'A,B', values: '3,2', t: 'evil', scheme: 'dark' });
```

Deno 사용자는 `deno add jsr:@x-cmd/draw`를 실행한 후 `jsr:@x-cmd/draw`에서 가져올 수 있습니다. 렌더링 코어는 네트워크나 파일에 접근하지 않으므로 제한된 환경에서도 실행하기에 적합합니다.

### 진입점과 데이터 경계 관리: 자체 서비스 운영

팀의 진입점을 통일하거나, 내부 네트워크에서 사용하거나, 공용 서비스에 의존하고 싶지 않을 때 적합합니다.

```sh
git clone https://github.com/x-cmd/draw && cd draw && npm install
npm run serve           # 로컬 서비스: http://localhost:8787/draw
bash scripts/setup.sh   # 자신의 Cloudflare 계정에 원클릭 배포
```

`DATA_REPO`, `DATA_BRANCH`, `GITHUB_TOKEN`을 설정하면 영구 단축 링크를 활성화할 수 있습니다. 설정하지 않아도 일반 GET 렌더링에는 영향이 없습니다. 자세한 내용은 [셀프 호스팅 가이드](../docs/1-overview/05-self-hosting/ko.md)를 참조하세요.
