X-CMD Draw เป็นเครื่องมือโอเพนซอร์สสำหรับสร้างกราฟ SVG: เพียงใส่ข้อมูลและสไตล์ใน URL ก็สามารถสร้างกราฟแท่ง กราฟเส้น แผนภาพ Sankey แผนภาพสถาปัตยกรรมระบบ แผนที่ความคิด และรูปภาพอื่น ๆ ได้หลากหลาย

![ตัวอย่างกราฟ X-CMD Draw](../docs/assets/draw.png)

คุณสามารถฝังกราฟลงใน README, issue, PR, บทความบล็อก และหน้าเว็บได้โดยตรง โดยไม่ต้องส่งออกหรืออัปโหลดไฟล์รูปภาพ ลิงก์และ SVG ยังคงเก็บข้อมูลและพารามิเตอร์ที่เครื่องอ่านได้ไว้: ผู้ชมเห็นเป็นภาพ ส่วน AI Agent สามารถอ่าน แก้ไข และสร้างใหม่ต่อได้โดยไม่ต้องตีความจากรูปภาพ

## ดูตัวอย่าง

ตั้งแต่การวิเคราะห์ประสิทธิภาพไปจนถึงการออกแบบสถาปัตยกรรม จากแผนที่ไปจนถึงตารางเวลา นิยามของภาพทั้งหมดจะถูกเก็บไว้ในลิงก์ คลิกที่ภาพเพื่อดูข้อมูล ปรับสไตล์ และสร้างใหม่ [ดูตัวอย่างกราฟเพิ่มเติม ↗](https://x-cmd.com/draw)

## เริ่มต้นอย่างรวดเร็ว

### 1. ให้ Agent เรียนรู้วิธีใช้ draw

ส่ง Prompt ด้านล่างให้ Agent ที่สามารถอ่านหน้าเว็บได้ บริการ draw ที่โฮสต์ให้ไม่จำเป็นต้องสมัครบัญชีหรือขอ API Key

```text
Read and follow https://raw.githubusercontent.com/x-cmd/draw/main/SKILL.md. From now on, whenever you write a README, issue, pull request, blog post, or chat message and need a chart, use x-cmd Draw to generate a link and embed it with image syntax instead of attaching image files.
```

### 2. บอกสิ่งที่คุณต้องการ

บอก Agent ว่าต้องใช้ข้อมูลใด ต้องการแสดงความสัมพันธ์แบบใด และจะใช้กราฟที่ไหน

> ฉันต้องการเพิ่มแผนภาพสถาปัตยกรรมให้ PR นี้ โปรดอ่านโค้ดและการสนทนาของการเปลี่ยนแปลงครั้งนี้ก่อน จากนั้นวาดเส้นทางการเรียกของคำขอจาก CLI ไปยัง API และฐานข้อมูล ระบุโมดูลที่เกี่ยวข้องและตำแหน่งที่แก้ไขในครั้งนี้ให้ชัดเจน แล้วฝังภาพลงในคำอธิบาย PR โดยตรง

หากใช้บ่อย คุณสามารถติดตั้ง [`SKILL.md`](../SKILL.md) ให้ Agent ที่รองรับ skills ในเครื่องได้ ตัวอย่างเช่น Claude Code ให้บันทึกเป็น `~/.claude/skills/draw/SKILL.md` หลังตั้งค่าเพียงครั้งเดียวก็สามารถบอกความต้องการได้โดยตรง

## ฟีเจอร์

- **🔗 URL คือกราฟ**: ข้อมูลและสไตล์เป็นข้อความที่อ่าน เปรียบเทียบ และนำเข้าระบบควบคุมเวอร์ชันได้ ลิงก์สามารถฝังลงใน Markdown และหน้าเว็บได้โดยตรง
- **🤖 ทั้งมนุษย์และ AI อ่านได้**: SVG ใช้สำหรับแสดงผล ส่วนข้อมูลและพารามิเตอร์ที่เครื่องอ่านได้ใช้สำหรับแก้ไขและสร้างใหม่ต่อ โดยไม่ต้องอนุมานข้อมูลย้อนจากรูปภาพ
- **📊 ความสามารถในการสร้างภาพที่หลากหลาย**: รองรับกราฟข้อมูล ผังงาน แผนภาพสถาปัตยกรรม แผนที่ความคิด แผนที่ และตารางเวลา รวมถึงใช้ ECharts เพื่อแสดงความสัมพันธ์ของข้อมูลที่ซับซ้อนยิ่งขึ้นได้
- **🖱️ แก้ไขแบบโต้ตอบด้วยภาพ**: คลิกตัวอย่างเพื่อเข้าสู่หน้าโต้ตอบ ดูข้อมูล ปรับพารามิเตอร์และสไตล์ แล้วคัดลอกลิงก์กราฟใหม่
- **🚀 เปิดกว้างและโฮสต์เองได้**: พัฒนาด้วย TypeScript และใช้สัญญาอนุญาต Apache-2.0 รองรับบริการออนไลน์, CLI, ไลบรารี npm / JSR และการปรับใช้บน Cloudflare Workers

### สร้างภาพอย่างรวดเร็ว: ใช้ URL โดยตรง

เหมาะสำหรับเขียนเอกสาร แบ่งปัน หรือสร้างภาพข้อมูลชั่วคราว เปิด [หน้าสาธิตและแก้ไขแบบโต้ตอบ](https://x-cmd.com/draw) ปรับข้อมูลและสไตล์แล้วคัดลอกลิงก์ หรือแก้ไขพารามิเตอร์ URL โดยตรงก็ได้

```md
![ตัวอย่างสัดส่วน](https://x-cmd.com/draw?type=pie&labels=A,B&values=3,2)
```

ผู้อ่านเห็นเป็นภาพ ส่วนคุณยังคงมีข้อความที่แก้ไขและตรวจสอบได้

### สร้างเป็นชุดหรือเชื่อมเข้ากับโครงการ: ใช้ CLI หรือไลบรารี

เหมาะสำหรับอัปเดตกราฟอัตโนมัติใน CI สร้างรายงานเป็นชุด ใช้งานออฟไลน์ และผสานเข้ากับแอปพลิเคชัน CLI และไลบรารีใช้พารามิเตอร์ชุดเดียวกับบริการที่โฮสต์ให้

```sh
npx @x-cmd/draw --type pie --labels A,B --values 3,2 --out pie.svg
```

หากต้องการสร้าง SVG แบบซิงโครนัสในโค้ด ให้ติดตั้งไลบรารีแล้วเรียก `draw`:

```sh
npm install @x-cmd/draw
```
```ts
import { draw } from '@x-cmd/draw';

const { svg } = draw({ type: 'pie', labels: 'A,B', values: '3,2', t: 'evil', scheme: 'dark' });
```

ผู้ใช้ Deno สามารถใช้ `deno add jsr:@x-cmd/draw` แล้วนำเข้าจาก `jsr:@x-cmd/draw` แกนเรนเดอร์ไม่เข้าถึงเครือข่ายหรือไฟล์ จึงเหมาะสำหรับใช้งานในสภาพแวดล้อมที่จำกัดสิทธิ์

### ควบคุมจุดเข้าใช้งานและขอบเขตข้อมูล: เรียกใช้บริการของคุณเอง

เหมาะสำหรับทีมที่ต้องการจุดเข้าใช้งานรวม ใช้งานในเครือข่ายภายใน หรือไม่ต้องการพึ่งพาบริการสาธารณะ:

```sh
git clone https://github.com/x-cmd/draw && cd draw && npm install
npm run serve           # บริการในเครื่อง: http://localhost:8787/draw
bash scripts/setup.sh   # ปรับใช้ในบัญชี Cloudflare ของคุณด้วยคลิกเดียว
```

เมื่อกำหนดค่า `DATA_REPO`, `DATA_BRANCH` และ `GITHUB_TOKEN` คุณจะเปิดใช้ลิงก์สั้นถาวรได้ หากไม่ได้กำหนดค่า การเรนเดอร์ GET ปกติจะไม่ได้รับผลกระทบ ดูรายละเอียดใน[คู่มือโฮสต์เอง](../docs/1-overview/05-self-hosting/th.md)
