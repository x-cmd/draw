# draw — SVG-діаграми з даними в URL

> [English](../README.md) | **Українська**

[![JSR score](https://img.shields.io/badge/dynamic/json?url=https%3A%2F%2Fapi.jsr.io%2Fscopes%2Fx-cmd%2Fpackages%2Fdraw&query=%24.score&label=JSR%20score&color=yellowgreen)](https://jsr.io/@x-cmd/draw/score)
[![OpenSSF Scorecard](https://api.securityscorecards.dev/projects/github.com/x-cmd/draw/badge)](https://securityscorecards.dev/viewer/?uri=github.com/x-cmd/draw)


X-CMD Draw — це інструмент з відкритим кодом для створення SVG-діаграм: додайте дані та стилі до URL, щоб створювати стовпчикові й лінійні діаграми, діаграми Санкея, схеми системної архітектури, інтелект-карти та багато іншого.

![Приклади діаграм X-CMD Draw](../docs/assets/draw.png)

Діаграми можна безпосередньо вбудовувати в README, issue, PR, дописи в блозі та вебсторінки — експортувати чи завантажувати файли зображень не потрібно. Посилання та SVG зберігають машиночитані дані й параметри: читачі бачать діаграму, а AI Agent може продовжити читання, редагування та повторну генерацію без розпізнавання зображення.

## Приклади

Від аналізу продуктивності до проєктування архітектури, від мап до розкладів — визначення кожної діаграми зберігається в посиланні. Натисніть зображення, щоб переглянути дані, змінити стиль і створити діаграму знову. [Більше прикладів діаграм ↗](https://x-cmd.com/draw)

## Швидкий старт

### 1. Навчіть Agent використовувати draw

Надішліть наведений нижче промпт агенту, який вміє читати вебсторінки. Для hosted-сервісу draw не потрібні реєстрація чи API Key:

```text
Read and follow https://raw.githubusercontent.com/x-cmd/draw/main/SKILL.md. From now on, whenever you write a README, issue, pull request, blog post, or chat message and need a chart, use x-cmd Draw to generate a link and embed it with image syntax instead of attaching image files.
```

### 2. Опишіть завдання

Укажіть агенту, які дані використовувати, які зв’язки показати та де буде використано діаграму:

> Я хочу додати архітектурну схему до цього PR. Спочатку прочитай код і обговорення цієї зміни, покажи ланцюжок викликів запиту від CLI до API та бази даних, познач задіяні модулі й місця, змінені в цьому PR, і встав діаграму безпосередньо в опис PR.

Якщо ви часто користуєтеся draw, установіть [`SKILL.md`](../SKILL.md) в Agent із підтримкою локальних skills. Наприклад, у Claude Code збережіть файл як `~/.claude/skills/draw/SKILL.md`; після одноразового налаштування можна одразу описувати завдання.

## Можливості

- **🔗 URL — це діаграма**: дані та стилі подано текстом, який можна читати, порівнювати й зберігати в системі контролю версій; посилання можна безпосередньо вбудовувати в Markdown і вебсторінки.
- **🤖 Зрозуміло людям і ШІ**: SVG відповідає за відображення, а машиночитані дані й параметри дають змогу продовжити редагування та повторну генерацію — відновлювати дані зі зображення не потрібно.
- **📊 Різноманітні діаграми**: дані, блок-схеми, архітектурні схеми, інтелект-карти, мапи й розклади, а також складніші зв’язки даних через ECharts.
- **🖱️ Візуальне інтерактивне редагування**: натисніть приклад, щоб відкрити інтерактивну сторінку, переглянути дані, налаштувати параметри й стилі та скопіювати нове посилання на діаграму.
- **🚀 Відкритий код і self-hosting**: TypeScript і ліцензія Apache-2.0; підтримуються онлайн-сервіс, CLI, бібліотека npm / JSR і розгортання в Cloudflare Workers.

## Не використовуєте Agent? Оберіть відповідний спосіб підключення

### Швидке створення: використовуйте URL безпосередньо

Підходить для документації, презентацій і разової візуалізації. Відкрийте [демо та інтерактивний редактор](https://x-cmd.com/draw), налаштуйте дані й стиль і скопіюйте посилання; також можна безпосередньо змінити параметри URL:

```md
![Приклад кругової діаграми](https://x-cmd.com/draw?type=pie&labels=A,B&values=3,2)
```

Читач бачить діаграму, а у вас залишається текст, який можна змінювати й перевіряти.

### Пакетна генерація та інтеграція: CLI або бібліотека

Підходить для автоматичного оновлення діаграм у CI, пакетного створення звітів, автономної роботи та інтеграції в застосунки. CLI і бібліотека використовують ті самі параметри, що й hosted-сервіс:

```sh
npx @x-cmd/draw --type pie --labels A,B --values 3,2 --out pie.svg
```

Щоб синхронно створювати SVG у коді, установіть бібліотеку та викличте `draw`:

```sh
npm install @x-cmd/draw
```
```ts
import { draw } from '@x-cmd/draw';

const { svg } = draw({ type: 'pie', labels: 'A,B', values: '3,2', t: 'evil', scheme: 'dark' });
```

Користувачі Deno можуть виконати `deno add jsr:@x-cmd/draw`, а потім імпортувати бібліотеку з `jsr:@x-cmd/draw`. Ядро рендерингу не звертається до мережі чи файлів, тому підходить для середовищ з обмеженими правами.

### Контроль точки входу та меж даних: власний сервіс

Підходить для єдиної командної точки доступу, використання у внутрішній мережі або ситуацій, коли ви не хочете залежати від публічного сервісу:

```sh
git clone https://github.com/x-cmd/draw && cd draw && npm install
npm run serve           # локальний сервіс: http://localhost:8787/draw
bash scripts/setup.sh   # розгортання однією командою у вашому акаунті Cloudflare
```

Після налаштування `DATA_REPO`, `DATA_BRANCH` і `GITHUB_TOKEN` можна ввімкнути постійні короткі посилання; без цих налаштувань звичайний GET-рендеринг продовжує працювати. Докладніше див. [посібник із self-hosting](../docs/1-overview/05-self-hosting/uk.md).
