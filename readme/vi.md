# draw — Biểu đồ SVG với dữ liệu nằm trong URL

> [English](../README.md) | **Tiếng Việt**

[![JSR score](https://img.shields.io/badge/dynamic/json?url=https%3A%2F%2Fapi.jsr.io%2Fscopes%2Fx-cmd%2Fpackages%2Fdraw&query=%24.score&label=JSR%20score&color=yellowgreen)](https://jsr.io/@x-cmd/draw/score)
[![OpenSSF Scorecard](https://api.securityscorecards.dev/projects/github.com/x-cmd/draw/badge)](https://securityscorecards.dev/viewer/?uri=github.com/x-cmd/draw)


X-CMD Draw là một công cụ tạo biểu đồ SVG mã nguồn mở: chỉ cần viết dữ liệu và kiểu dáng vào URL là bạn có thể tạo biểu đồ cột, biểu đồ đường, sơ đồ Sankey, sơ đồ kiến trúc hệ thống, sơ đồ tư duy và nhiều loại hình khác.

Bạn có thể nhúng biểu đồ trực tiếp vào README, issue, PR, bài blog và trang web mà không cần xuất hay tải tệp hình ảnh lên. Liên kết và SVG vẫn giữ dữ liệu cùng tham số ở dạng máy đọc được: người xem nhìn thấy hình, còn AI Agent có thể tiếp tục đọc, chỉnh sửa và tạo lại mà không cần nhận diện hình ảnh.

## Xem trước

Từ phân tích hiệu năng đến thiết kế kiến trúc, từ bản đồ đến lịch trình, định nghĩa của mỗi hình đều được lưu trong liên kết. Nhấp vào hình để xem dữ liệu, điều chỉnh kiểu dáng và tạo lại. [Xem thêm ví dụ biểu đồ ↗](https://x-cmd.com/draw)

## Bắt đầu nhanh

### 1. Cho Agent biết cách sử dụng draw

Gửi Prompt dưới đây cho Agent có khả năng đọc trang web. Dịch vụ draw trực tuyến không yêu cầu đăng ký tài khoản hoặc xin API Key.

```text
Read and follow https://raw.githubusercontent.com/x-cmd/draw/main/skills/x-cmd-draw/SKILL.md. From now on, whenever you write a README, issue, pull request, blog post, or chat message and need a chart, use x-cmd Draw to generate a link and embed it with image syntax instead of attaching image files.
```

### 2. Nói rõ nhu cầu của bạn

Cho Agent biết cần dùng dữ liệu nào, thể hiện mối quan hệ nào và biểu đồ sẽ được dùng ở đâu.

```text
Thêm sơ đồ kiến trúc vào README, thể hiện đường đi của yêu cầu từ CLI qua API đến cơ sở dữ liệu.
```text

Nếu thường xuyên sử dụng, bạn có thể cài [`SKILL.md`](../skills/x-cmd-draw/SKILL.md) vào Agent hỗ trợ skills cục bộ. Với Claude Code, hãy lưu tại `~/.claude/skills/draw/SKILL.md`; sau khi cấu hình một lần, bạn chỉ cần mô tả trực tiếp nhu cầu.

## Tính năng

- **🔗 URL chính là biểu đồ**: dữ liệu và kiểu dáng đều là văn bản có thể đọc, so sánh và đưa vào quản lý phiên bản; liên kết có thể nhúng trực tiếp vào Markdown và trang web.
- **🤖 Con người và AI đều đọc được**: SVG dùng để hiển thị, còn dữ liệu và tham số máy đọc được dùng để tiếp tục chỉnh sửa và tạo lại, không cần suy ra dữ liệu từ hình ảnh.
- **📊 Khả năng tạo hình phong phú**: hỗ trợ biểu đồ dữ liệu, lưu đồ, sơ đồ kiến trúc, sơ đồ tư duy, bản đồ và lịch trình; cũng có thể dùng ECharts để thể hiện các quan hệ dữ liệu phức tạp hơn.
- **🖱️ Chỉnh sửa tương tác trực quan**: nhấp vào ví dụ để mở trang tương tác, xem dữ liệu, điều chỉnh tham số và kiểu dáng, rồi sao chép liên kết biểu đồ mới.
- **🚀 Mở và có thể tự lưu trữ**: xây dựng bằng TypeScript, sử dụng giấy phép Apache-2.0; hỗ trợ dịch vụ trực tuyến, CLI, thư viện npm / JSR và triển khai Cloudflare Workers.

## Không dùng Agent? Chọn cách tích hợp phù hợp với bạn

### Tạo hình nhanh: dùng URL trực tiếp

Phù hợp để viết tài liệu, chia sẻ hoặc tạm thời trực quan hóa dữ liệu. Mở [trang demo và chỉnh sửa tương tác](https://x-cmd.com/draw), điều chỉnh dữ liệu và kiểu dáng rồi sao chép liên kết; bạn cũng có thể sửa trực tiếp tham số URL.

```md
![Ví dụ tỷ trọng](https://x-cmd.com/draw?type=pie&labels=A,B&values=3,2)
```

Người đọc nhìn thấy hình, còn bạn giữ lại một đoạn văn bản có thể chỉnh sửa và xem xét.

### Tạo hàng loạt hoặc tích hợp vào dự án: dùng CLI hoặc thư viện

Phù hợp cho việc tự động cập nhật biểu đồ trong CI, tạo báo cáo hàng loạt, dùng ngoại tuyến và tích hợp ứng dụng. CLI và thư viện dùng cùng bộ tham số với dịch vụ trực tuyến.

```sh
npx @x-cmd/draw --type pie --labels A,B --values 3,2 --out pie.svg
```

Khi cần tạo SVG đồng bộ trong mã, hãy cài thư viện và gọi `draw`:

```sh
npm install @x-cmd/draw
```
```ts
import { draw } from '@x-cmd/draw';

const { svg } = draw({ type: 'pie', labels: 'A,B', values: '3,2', t: 'evil', scheme: 'dark' });
```

Người dùng Deno có thể chạy `deno add jsr:@x-cmd/draw`, sau đó nhập từ `jsr:@x-cmd/draw`. Lõi kết xuất không truy cập mạng hoặc tệp nên phù hợp để chạy trong môi trường bị hạn chế.

### Kiểm soát điểm truy cập và ranh giới dữ liệu: chạy dịch vụ của riêng bạn

Phù hợp khi nhóm cần một điểm truy cập thống nhất, sử dụng trong mạng nội bộ hoặc không muốn phụ thuộc vào dịch vụ công cộng:

```sh
git clone https://github.com/x-cmd/draw && cd draw && npm install
npm run serve           # Dịch vụ cục bộ: http://localhost:8787/draw
bash scripts/setup.sh   # Triển khai một chạm lên tài khoản Cloudflare của bạn
```

Bạn có thể bật liên kết ngắn vĩnh viễn bằng cách cấu hình `DATA_REPO`, `DATA_BRANCH` và `GITHUB_TOKEN`; nếu chưa cấu hình, việc kết xuất GET thông thường không bị ảnh hưởng. Xem [hướng dẫn tự lưu trữ](../docs/1-overview/05-self-hosting/vi.md) để biết chi tiết.
