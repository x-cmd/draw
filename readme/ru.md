# draw — SVG-графики с данными в URL

> [English](../README.md) | **Русский**

[![JSR score](https://img.shields.io/badge/dynamic/json?url=https%3A%2F%2Fapi.jsr.io%2Fscopes%2Fx-cmd%2Fpackages%2Fdraw&query=%24.score&label=JSR%20score&color=yellowgreen)](https://jsr.io/@x-cmd/draw/score)
[![OpenSSF Scorecard](https://api.securityscorecards.dev/projects/github.com/x-cmd/draw/badge)](https://securityscorecards.dev/viewer/?uri=github.com/x-cmd/draw)


X-CMD Draw — это инструмент с открытым исходным кодом для создания SVG-диаграмм: укажите данные и стили в URL, чтобы создавать столбчатые и линейные диаграммы, диаграммы Санкея, схемы системной архитектуры, интеллект-карты и многое другое.

Диаграммы можно напрямую встраивать в README, issue, PR, статьи блога и веб-страницы — экспортировать или загружать файлы изображений не нужно. Ссылки и SVG сохраняют машиночитаемые данные и параметры: читатели видят диаграмму, а AI Agent может продолжить чтение, изменение и повторную генерацию без распознавания изображения.

## Примеры

От анализа производительности до проектирования архитектуры, от карт до расписаний — определение каждой диаграммы хранится в ссылке. Нажмите на изображение, чтобы просмотреть данные, изменить стиль и создать диаграмму заново. [Другие примеры диаграмм ↗](https://x-cmd.com/draw)

## Быстрый старт

### 1. Научите Agent использовать draw

Отправьте следующий промпт агенту, который умеет читать веб-страницы. Для hosted-сервиса draw не нужны регистрация или API Key:

```text
Read and follow https://raw.githubusercontent.com/x-cmd/draw/main/SKILL.md. From now on, whenever you write a README, issue, pull request, blog post, or chat message and need a chart, use x-cmd Draw to generate a link and embed it with image syntax instead of attaching image files.
```

### 2. Опишите задачу

Укажите агенту, какие данные использовать, какие связи показать и где будет использоваться диаграмма:

> Я хочу добавить архитектурную схему в этот PR. Сначала прочитай код и обсуждение этого изменения, покажи цепочку вызовов запроса от CLI к API и базе данных, отметь задействованные модули и места, изменённые в этом PR, и вставь диаграмму прямо в описание PR.

Если вы пользуетесь draw часто, установите [`SKILL.md`](../SKILL.md) в Agent с поддержкой локальных skills. Например, в Claude Code сохраните файл как `~/.claude/skills/draw/SKILL.md`; после однократной настройки можно сразу описывать задачу.

## Возможности

- **🔗 URL — это диаграмма**: данные и стили представлены текстом, который можно читать, сравнивать и хранить в системе контроля версий; ссылки можно напрямую встраивать в Markdown и веб-страницы.
- **🤖 Понятно людям и ИИ**: SVG отвечает за отображение, а машиночитаемые данные и параметры позволяют продолжить редактирование и повторную генерацию — извлекать данные из изображения не нужно.
- **📊 Разнообразные диаграммы**: данные, блок-схемы, архитектурные схемы, интеллект-карты, карты и расписания, а также более сложные связи данных через ECharts.
- **🖱️ Визуальное интерактивное редактирование**: нажмите на пример, чтобы открыть интерактивную страницу, просмотреть данные, настроить параметры и стили и скопировать новую ссылку на диаграмму.
- **🚀 Открытый код и self-hosting**: TypeScript и лицензия Apache-2.0; поддерживаются онлайн-сервис, CLI, библиотека npm / JSR и развёртывание в Cloudflare Workers.

## Не используете Agent? Выберите подходящий способ подключения

### Быстрое создание: используйте URL напрямую

Подходит для документации, презентаций и разовой визуализации. Откройте [демо и интерактивный редактор](https://x-cmd.com/draw), настройте данные и стиль и скопируйте ссылку; можно также изменить параметры URL напрямую:

```md
![Пример круговой диаграммы](https://x-cmd.com/draw?type=pie&labels=A,B&values=3,2)
```

Читатель видит диаграмму, а у вас остаётся текст, который можно изменять и проверять.

### Пакетная генерация и интеграция: CLI или библиотека

Подходит для автоматического обновления диаграмм в CI, пакетного создания отчётов, автономной работы и интеграции в приложения. CLI и библиотека используют те же параметры, что и hosted-сервис:

```sh
npx @x-cmd/draw --type pie --labels A,B --values 3,2 --out pie.svg
```

Чтобы синхронно создавать SVG в коде, установите библиотеку и вызовите `draw`:

```sh
npm install @x-cmd/draw
```
```ts
import { draw } from '@x-cmd/draw';

const { svg } = draw({ type: 'pie', labels: 'A,B', values: '3,2', t: 'evil', scheme: 'dark' });
```

Пользователи Deno могут выполнить `deno add jsr:@x-cmd/draw`, а затем импортировать библиотеку из `jsr:@x-cmd/draw`. Ядро рендеринга не обращается к сети или файлам, поэтому подходит для сред с ограниченными правами.

### Контроль входной точки и границ данных: собственный сервис

Подходит для единой командной точки доступа, использования во внутренней сети или ситуаций, когда вы не хотите зависеть от публичного сервиса:

```sh
git clone https://github.com/x-cmd/draw && cd draw && npm install
npm run serve           # локальный сервис: http://localhost:8787/draw
bash scripts/setup.sh   # развёртывание одной командой в вашем аккаунте Cloudflare
```

После настройки `DATA_REPO`, `DATA_BRANCH` и `GITHUB_TOKEN` можно включить постоянные короткие ссылки; без этих настроек обычный GET-рендеринг продолжает работать. Подробнее см. [руководство по self-hosting](../docs/1-overview/05-self-hosting/ru.md).

## Разработка

```sh
npm install
npm run dev      # локальный запуск через wrangler dev
npm test         # vitest
npm run check    # tsc --noEmit × 3 (worker / node / build)
npm run build    # создаёт dist/ (библиотека npm + CLI)
npm run deploy   # wrangler deploy
```
